# Team Desk (the Embed recipe's starting point)

A small sample product: a manager's view of their week's one-to-ones, with a **Practice the conversation** panel that has nothing in it yet. The Embed recipe puts a practice room from the Conversations API inside that panel, in Team Desk's own look, without changing the rest of the product.

```sh
npm start
```

Open http://localhost:3000. Press **Practice with Jon**: today it says "Practice is coming soon."

Node 24 or later. No packages to install. The finished version is the `embed` folder, one level up.
